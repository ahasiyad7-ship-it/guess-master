# 🎯 Guess Master

A simple & fun number guessing game built with HTML, CSS & JavaScript.

**Live Demo:** https://ahasiyad7-ship-it.github.io/guess-master/

## Features
- Random number from 0 to 9
- Smart hints - Too High / Too Low
- Attempts counter
- Restart option
- Mobile responsive

## Tech Stack
HTML | CSS | JavaScript

## How to Play
1. Guess a number between 0 and 9
2. Click Check
3. Follow the hints and win!
